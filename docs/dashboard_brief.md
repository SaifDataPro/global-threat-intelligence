# SOC Dashboard Brief

## Audience
The SOC Manager — responsible for the overall security 
posture of the organisation. Uses the dashboard daily 
as the first touchpoint of the working day to assess 
overnight and current threat activity.

## Three Key Decisions This Dashboard Must Enable

1. **Prioritise systems and patches**
   Which vulnerabilities or threat types are actively 
   targeting the firm right now — and what needs to be 
   patched or hardened first?

2. **Resource allocation**
   Is the current analyst team sufficient for today's 
   threat load, or does capacity need to be scaled up 
   for specific cases or departments?

3. **Escalation**
   Is the severity and nature of current threat activity 
   significant enough to escalate to the CISO, legal, 
   or external authorities?

## Success Criteria

The SOC Manager no longer performs manual correlation 
between internal firewall logs and external threat intel 
sources like the OTX web app. All data is pre-correlated 
and self-serve.

**Measurable signal:** The SOC Manager can answer any of 
the 5 key risk questions in under 2 minutes without 
opening another tool.

This frees analyst time from searching for data toward 
thinking critically about solutions and responses.
